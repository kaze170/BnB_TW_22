# 爆爆王 BnB TW — Web 完全還原

Faithful web restoration of Nexon **Crazy Arcade BnB（彈水阿給／爆爆王）台灣版**.
All client logic, UI layout, gameplay constants and assets are derived strictly
from the original `CA.exe` (IDA export `CA.exe.c`) and the original client assets.
**Only the server is original** (per project decision).

## Stack
- **Bun 1.4.4** — runtime, bundler, dev/WebSocket server
- **TypeScript 7.1.0-beta** — native compiler (`tsc`)
- **WebGPU** — primary 2D sprite renderer (Canvas2D fallback)

## Run
```bash
bun install
bun run assets   # convert extracted/ -> build/assets + manifest (auto-run on first server start)
bun run dev      # http://0.0.0.0:3000  (serves client + assets + /ws game server)
bun run typecheck
```
The original assets live in `extracted/` (already unpacked from `.idd/.idx`).
Generated web assets go to `build/` (git-ignored, regenerated by the pipeline).

## Architecture
```
tools/                asset pipeline (I16 RLE decoder -> PNG, manifest)
  i16.ts              faithful port of CDataI16::sub_678590 + sub_66F050
  png.ts              minimal RGBA PNG encoder
  asset-pipeline.ts   walks extracted/, emits build/assets + build/manifest.json
src/
  shared/protocol.ts  client<->server messages (server is original)
  client/
    engine/           renderer (WebGPU/Canvas2D), assets, input, types (800x600, 40px tile)
    ui/               CCtrlButton/CCtrlEdit ports, text helper
    stages/           CStage scene flow: Login -> SelectServer -> Lobby -> Prepare -> Game
    net/client.ts     WebSocket client
  server/             Bun HTTP + WebSocket game server (original)
docs/REVERSE_ENGINEERING.md   analysis of record (formats, constants, exe line refs)
```
